| D3 | Platforms: iOS + Android; India + global. | 2026-11-18 |
| D4 | Paywall: soft, right after the first wow; after it, the user lands in the app. | 2026-11-26 |

Warm off-white canvas; raised cards nested in a tray with soft layered shadows; serif + grotesk type pairing; glossy pill tags; full-bleed blurred gradient cards; floating pill tab bar; collectible cards ("Habitat"). | 2026-11-26 |
| D6 | Today's scope: onboarding, wow/activation event, paywall, tab structure (what each tab holds), packaging and user flows. Progress, mascot, image style and prototype format are deep dives for later. | 2026-11-26 |
| D7 | No chat thread as the main view; it would look like a prettier ChatGPT. In Paper, explore several Exploration formats (component, page and page-level), built around 2–3 personas and their real questions. Bring in real-world curiosity. | 2026-11-26 |
| D8 | Going deeper: an Exploration ends in rabbit holes; following one stacks a new Exploration with a trail. This is part of the first Exploration. | 2026-11-26 |
| D9 | Activation event: finish the first Exploration + interact with its diagram + follow 1 rabbit hole, in the first session. Practice modes sit on top so the user applies what they learned. | 2026-11-26 |
| D10 | Onboarding: longer and personalising (it collects data) but interactive at each step; suggested prompts are pre-generated so the wow is instant. Sign-in comes after the wow. | 2026-11-26 |
| D11 | Paywall: at the end of the first Exploration (rabbit holes screen), 3-day trial, closable. Free tier is 3 Explorations a day; deep dives are paid. | 2026-11-26 |
| D12 | Tabs: Today (recommended Explorations + unfinished ones) · Explore (others' rabbit holes, like Wondering's courses) · Practice (practice on Explorations) · Profile (your Explorations + learning-node graph). **Ask** sits outside the tab bar and opens an infinite, zoomable canvas where Explorations are connected nodes; the same canvas is used for others' Explorations. | 2026-11-26 |
| D13 | Canvas reference: "Your People" bubble field (x.com/premiumtantan/status/2118391672430313700). Centre node large, outer nodes smaller; pinch to zoom; tap to go deep. | 2026-11-26 |
| D14 | Practice (V0): Daily mix (2 min on concepts that are due, rotating formats) + Practice an Exploration (6–8 interactive questions). Friend challenge later. | 2026-11-26 |
| D15 | Ask opens a new, empty canvas each time ("What would you like to learn?"). Canvas works as a bubble field: zoom in for more detail, tap to open. | 2026-11-26 |
| D16 | Personas, sorted on two axes (wide ↔ deep, joy ↔ use): **Wanderer** (Riya), **Builder** (Sam: learning a new field for work), **Student** (Meera), **Specialist** (a doctor, researcher or engineer already deep in their field; wants rigor, sources and no dumbing down). The Specialist shapes a depth dial and visible sources; V0 targets the first three. | 2026-11-26 |
| D17 | Every design gets two versions: **Vision** (divergent; the app at full ambition) and **V0** (pared down and shippable). Start with little text and simple visuals, then iterate. | 2026-11-26 |
| D18 | Exploration format: intent × concept shape × person picks the lead card; every Exploration runs Hook → Aha → Unfold → Check → Next. Approved to try. | 2026-11-26 |
| D19 | Onboarding imports curiosity (inspired by Quest). Ask "Where do you go when you're curious?" → V0: a copy prompt for ChatGPT/Claude/Gemini whose answer is pasted back (fallback: screenshot of the chat list, or a bubble picker) → show their curiosity map → the first Exploration is a question they already had. Vision: connect ChatGPT, Gemini, YouTube, Podcasts, etc. | 2026-11-26 |
| D20 | Tabs: **Today · Explore · Practice · Memory**, plus **Ask** (a new empty canvas each time). Memory holds every past canvas; account and settings go behind an avatar. | 2026-11-26 |
| D21 | Design system first, screens after. Serif headings (Newsreader) rejected. Choosing one sans family for everything: Satoshi, Inter Tight, Geist, Schibsted Grotesk, Instrument Sans or Host Grotesk (Paper › 00 Foundations). | 2026-11-26 |
| D22 | Design system v2 replicates Quest's object language (research/design-system-breakdown.md). Cool studio-grey background with ambient washes; keycap controls (face + lit edge + solid lip + hairline + shadow); bezel containers; flat fields; glossy hue tags; light serif titles + grotesk UI; six saturated hues. No black primary button. Fonts for now: Source Serif 4 + Inter Display (licensed originals TBD). Paper › 00 Design system. | 2026-11-26 |
| D23 | Use Quest's exact font and colours. Font = **Season** (Displaay) variable: SERF 0 at 550–650 for the interface, SERF 50 ("Season Mix") at 600–670 for titles and signature buttons, confirmed in new.quest CSS. It needs a licence and a local install before Paper can render it; stand-ins until then. Colours = Quest's DreamCanvas and text greys, plus the CarvedChip button recipe (research/design-system-breakdown.md §6). | 2026-11-26 |
| D24 | Typeface chosen (option D): **Bricolage Grotesque** 600, −3% tracking (−1% on buttons) for titles, big numbers, card titles and button labels; **Inter Display** 500–600 for body, labels, tabs, fields and eyebrows. Both are free. Replaces Season (D23); Quest's colours and CarvedChip stay. | 2026-11-26 |
| D25 | Colour has 4 layers. (1) Neutrals from Quest, with two greys fixed for contrast (#625E5A for text on the background, #77736E for eyebrows). (2) Brand **Ember** (#F26B1D signature; 600 #C2500C under white text; 700 #A8430A for links), used only for Ask, the main button, the logo, celebrations and links. (3) **8 subject families**: Body, Mind, Space, Tech, Nature, Society, History, Arts, each deep/base/light/tint; white text on deep only. (4) Feedback, in practice only: right #12A58A, wrong #E5484D, hint = Ember, always with an icon. Features get no colour. Browsing stays grey; an Exploration takes its subject's colour. No dark mode. The Ask orb style (A/B/C) is still open. | 2026-11-26 |
| D26 | Brand primary = **Electric cobalt**, replacing Ember. 500 #1F5BE0 (5.8:1 with white), 600 #1F55D6 under white text, 700 #1A47B8 for links, 900 #0B2A66 at the top of the lit door, 300 #7FA3FF, 50 #EEF3FF. Used for Ask, the main button, streaks and celebrations, links, and hints. **Space subject moved to dusky midnight** (#2F3766 / #56619A) so cobalt is the only electric blue. Ask = sparkle icon + "Ask" label. Still open: subject cover style (linear / enamel / arcs / soft tint), tab bar option (1 stacked / 2 expanding), Ask style (carved vs lit). | 2026-11-26 |
| D27 | Tabs: **Ask (home, first tab, like ChatGPT) · Explore · Practice · Memory**. The Today tab is dropped: "continue" and sparks move into Ask home and Explore's "For you". Ask is no longer a separate button. | 2026-11-27 |
| D28 | Working mode: define the core flows in chat (plain language and text maps); visuals go to Paper as early explorations (archive later); then 2–3 parallel chats detail the flows. | 2026-11-27 |
| D29 | Character = **a particle brain, brain-shaped by default** (not a sphere), designed light-mode first: solid cobalt ink dots sized and shaded by depth, no glow. Behaviour borrowed from Perplexity's voice orb: slow rotation, each dot on its own orbit, touch ripples, voice waves. States: idle, listening, thinking (neurons firing along the folds), touch, answer forms (dots become the topic in its subject colour), your brain (regions in subject colours = Memory). Production samples points from a real brain model. Paper › 04 Orb › "Brain on light". | 2026-11-27 |
| D30 | Process: go deep one flow at a time where the flow *sets patterns* (activation first: onboarding → first Exploration → paywall), iterating with the user to 80–90%; then flows that *reuse patterns* (Explore, Practice, Memory) run in parallel chats; then a final polish pass. | 2026-11-27 |
| D31 | Journey maps for all 3 onboarding directions × 4 personas (`flows/onboarding-06-journey-maps.md`, Paper › 07 Journey maps). Working hypothesis: **Ask is the spine**. When the composer sits idle, Wonder's guess-first spark appears, and Wonder's taste test becomes Ask's step 5. Seen's Wrapped becomes the upgrade moment, not the front door. All three are still prototyped to test this. Why: Ask gives every persona the fastest wow (~15–20s); Seen's wow comes after its hardest step; Wonder loses Sam and Dev in the first ~55s. | 2026-11-27 |
| D32 | Onboarding v3 (PM path), live at cortex-onboarding-v3.vercel.app (Part A) and /partb/ (Part B). **Font: Geist** for everything (replaces D24 Bricolage + Inter). **Icons: style A**, a solid glyph in its own colour gradient on a white tile; each goal and role has its own colour, and the brain morphs into the icon as dots in that gradient. Rejected: 3D clay image icons (not premium), line icons (flat), app-tile, duotone and dotted styles (Paper › 09). | 2026-11-27 |
